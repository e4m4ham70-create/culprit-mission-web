범인찾기 미션 웹페이지

파일 구성
- index.html
- hint1.html
- hint2.html
- hint3.html
- hint4.html
- style.css
- script.js

사용 방법
1. 폴더 안의 파일을 모두 같은 위치에 둡니다.
2. index.html을 열면 메인 화면이 표시됩니다.
3. 실제 수업에서는 hint1~hint4 페이지 주소를 각각 QR코드로 만들어 학생들에게 따로 제공할 수 있습니다.
4. 학생이 입력한 한글 해석은 해당 브라우저의 localStorage에 자동 저장됩니다.

GitHub Pages
저장소 최상위에 위 파일을 모두 업로드한 뒤 GitHub Pages를 활성화하면 됩니다.
